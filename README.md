
# FSSAI Licensing Portal
A professional web-based portal for industrial food safety compliance and FSSAI registration.

## Features
- Dynamic form with conditional document uploads (Basic/State/Central).
- Google Apps Script backend for secure data handling.
- Integrated with Google Sheets for real-time application tracking.
- Responsive UI built with Bootstrap 5 and Outfit Google Fonts.

## Tech Stack
- **Frontend:** HTML5, CSS3, JavaScript (ES6+), Bootstrap 5.
- **Backend:** Google Apps Script (GAS).
- **Database:** Google Sheets API.
- **Deployment:** Vercel / GitHub Pages.
